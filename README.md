Nutri-Visual est une application web moderne conçue pour aider les utilisateurs à mieux comprendre leur profil nutritionnel grâce à des indicateurs simples, lisibles et accessibles.

L’outil permet de calculer rapidement :

- l’IMC,
- les besoins caloriques journaliers,
- les besoins en eau,
- et la catégorie associée à chaque résultat.

Le projet a été pensé pour une expérience fluide, responsive et légère, sans inscription ni backend complexe.

## ✨ Fonctionnalités

- Calcul de l’IMC avec interprétation visuelle
- Estimation des besoins caloriques selon le sexe, l’âge, la taille et le niveau d’activité
- Calcul de l’hydratation quotidienne recommandée
- Sauvegarde locale du profil dans le navigateur
- Mode clair / mode sombre
- Interface moderne et responsive pour mobile et desktop
- FAQ et présentation produit pour une meilleure expérience utilisateur

## 🧰 Stack technique

- React
- Vite
- JavaScript
- Lucide React
- CSS moderne avec variables et design system

## 🚀 Démarrage rapide

Depuis le dossier du projet :

```bash
npm install
npm run dev
```

Puis ouvrez l’URL suivante dans votre navigateur :

```text
http://localhost:4173/
```
